# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-07

### Added
- Initial release of React TypeScript Boilerplate
- React 19 with TypeScript 5
- Vite 7 for blazing fast development
- Tailwind CSS v4 with dark mode support
- Feature-Sliced Design (FSD) architecture
- Authentication system with protected routes
- Internationalization (i18n) - English & Vietnamese
- Zustand for state management
- Axios with interceptors
- React Hook Form + Zod validation
- ESLint 9 with flat config
- Prettier code formatting
- Husky + lint-staged pre-commit hooks
- GitHub Actions CI/CD pipeline
- Playwright E2E testing setup
- Comprehensive documentation
- Responsive design for all screen sizes
- Mock authentication with default test account

### Features
- 🔐 Authentication with mock login (test@example.com/123456)
